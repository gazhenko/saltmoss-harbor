# Credits

**Saltmoss Harbor** — design, code, sculpting tools, music and sound by Jemmy Gazhenko, built with Claude.

## Everything is made from code
- **Models**: every puppet, prop, fish, treasure, building and the coast are sculpted procedurally from signed-distance
  clay primitives by `Tools/clay` (Python + NumPy + scikit-image), meshed with marching cubes and exported as
  `.claymesh` files that Unity imports through `ClayMeshImporter`.
- **Textures**: fingerprints, tool marks, sea ripples, the painted sky and paper grain are generated by
  `Tools/art/clay_textures.py`; the clay UI slabs by `Tools/art/ui_sprites.py`; the clay logo by `Tools/art/logo.py`.
- **Music and sound**: every note and effect is synthesized in Python (`Tools/audio`): accordion, ukulele (Karplus-Strong),
  glockenspiel, whistle, fiddle, bass, drums, waves, gulls, the old diesel, winches and creaks. No samples or recordings.
- **Voices**: the Animalese-style voice blips are synthesized at runtime by `VoiceBlips.cs` (formant synthesis).
